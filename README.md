# 💬 Scholar Chat

A real-time chat application built with **Flutter** and **Firebase**.

This project was built as part of my journey to improve my Flutter development skills and gain practical experience with Firebase Authentication and Cloud Firestore.

## 📱 Features

* 🔐 User registration and login
* 🔥 Firebase Authentication
* 💬 Real-time messaging with Cloud Firestore
* 👤 Display messages based on the authenticated user
* 🕐 Messages ordered by creation time
* 📜 Automatic chat scrolling
* ⏳ Loading state
* 🎨 Clean and simple user interface

## 🛠️ Technologies

* **Flutter**
* **Dart**
* **Firebase Authentication**
* **Cloud Firestore**

## 🧠 What I Learned

While building this project, I practiced:

* Connecting Flutter applications with Firebase
* Working with Firestore Collections and Documents
* Using `StreamBuilder` for real-time data
* Working with Streams and Snapshots
* Creating Dart Models and using `fromJson`
* Handling Firebase Authentication
* Managing chat message ordering
* Using `ScrollController`
* Building reusable and organized Flutter code

 ##⚙️ Getting Started

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Navigate to the project

```bash
cd scholar_chat
```

### 3. Install dependencies

```bash
flutter pub get
```

### 4. Configure Firebase

Connect the project to your Firebase project and make sure Firebase Authentication and Cloud Firestore are enabled.

### 5. Run the application

```bash
flutter run
```
